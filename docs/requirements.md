# WhaleMaid · 需求编号表（REQ）

> 唯一现行版。文档↔代码唯一映射的锚：代码模块头部写 `SPEC: docs/protocol.md#PROTO-xxx`，PR 引用 REQ 编号。
> 协议/代码位置列在实施时回填。Phase B 条目标注「仅设计，不实现」，**不得进入开源仓库**。

## MVP（REQ-001..016）

| ID | 需求 | 验收标准 | 关联 ADR |
|---|---|---|---|
| REQ-001 | **IP 直连模式**：手机经 `http(s)://<主机IP>:<端口>/m` 访问移动端，长期密码鉴权，零服务器依赖 | 局域网内手机完成 登录→会话列表→收发消息 | ADR-019 |
| REQ-002 | **长期密码**（无人值守）：首次配对后持久凭据，之后免桌面操作；改密后旧凭据立即失效 | 双方重启后仍可连接；改密后旧密码被拒 | ADR-004/012 |
| REQ-003 | **临时密码**：一次性/限时，用于临时设备 | 用过即失效；到期失效 | ADR-004 |
| REQ-004 | **授权名单与吊销**：宿主维护授权设备名单，单设备吊销即时生效 | 吊销后该设备下一次请求即被拒 | ADR-012 |
| REQ-005 | **原生会话**：列表/历史/继续/新建，与桌面端同一 session 存储 | 手机新建的会话在电脑上立即可见 | ADR-024 |
| REQ-006 | **聊天流**：实时输出、折叠深度思考与工具调用、停止任务 | 流式可见；停止后任务中断 | — |
| REQ-007 | **模型与思考强度**切换 | 切换后下一轮生效 | — |
| REQ-008 | **权限预设**选择与确认 | 与桌面端行为一致 | — |
| REQ-009 | **工作区创建**（browse seam）：手机浏览主机目录→建/选文件夹→`workspace.create`；默认限工作区根，全盘浏览需长期密码二次确认 | 手机新建工作区并开出新会话 | ADR-008 |
| REQ-010 | **目录模式**：长回复按标题折叠导航 | 长回复出现目录且可跳转 | — |
| REQ-011 | **引用复制**：选中消息段落一键复制 | 多段选择可复制到剪贴板 | — |
| REQ-012 | **自托管中继**：docker 一键部署（rathole 扩展 + 控制面） | 公网服务器部署后手机经中继连接家中主机 | ADR-006 |
| REQ-013 | **协议信封**：版本化 + capability 广播 + 三通道类型化流 | 未知 capability 被忽略；老版本正常降级 | ADR-021 |
| REQ-014 | **E2E 加密**：会话通道中继不可读 | 中继侧抓包只见密文 | ADR-025 |
| REQ-015 | **设备身份密钥**：WebCrypto 不可导出密钥对；指纹展示 | 重装需重新配对 | ADR-013 |
| REQ-016 | **宿主本地审计日志**（连接元数据，不含内容） | 可查时间/设备/动作 | — |
| REQ-017 | **宿主插件跨平台**：macOS / Ubuntu / Windows 行为一致（目录选择、凭据存储、进程管理） | 三平台安装同一插件包均可运行 | — |
| REQ-018 | **统一 API 契约**：客户端只依赖公开 API，UI 与后端解耦（为 Android/iOS/鸿蒙铺路） | 移动 UI 与宿主通信全部走 API 定义文件，无私有通道 | ADR-029 |

## V1（REQ-020..025）

| ID | 需求 | 验收标准 | 关联 ADR |
|---|---|---|---|
| REQ-020 | **语音 BYOK**（厂商可插拔）：录音→宿主→用户自填 ASR API→转写回填输入框 | 中文语音转文字可用；key 只存宿主 | ADR-009/013 |
| REQ-021 | **热词附加插件**：独立开源、不默认安装；宿主本地抽取→只传词表 | 未安装则无此通道；服务端只见词表不见正文 | ADR-010 |
| REQ-022 | **视觉适配 BYOK**：图片→OCR/简述（DeepSeek-OCR/通义 VL）→嵌入 DeepSeek 请求 | 图片请求被转成文本描述并入请求 | ADR-011 |
| REQ-023 | **通知**：Web Push + Telegram 桥 | 任务完成/需审批时手机收到推送 | ADR-015 |
| REQ-024 | **多机切换**：设备列表多主机 | 列表切换即连接 | — |
| REQ-025 | **临时密码分享 + 会话总结** | 分享链接一次性可用；总结按钮产出摘要 | — |
