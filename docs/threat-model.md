# WhaleMaid · 威胁模型 v1（TM）

> 唯一现行版。每个对策编号 TM-xxx，实施时映射到代码检查点（architecture.md 回填）。目标：覆盖远程桌面同级风险，明确残余风险。

---

## 资产

| 资产 | 等级 |
|---|---|
| 用户电脑与其中数据（工作区/会话内容） | 最高 |
| 第三方 API key（宿主侧，用户 BYOK） | 高 |
| 设备凭据（手机侧私钥/token） | 高 |
| 中继可用性与匿名性（官方 SaaS 声誉） | 中 |

## 威胁者

T1 网络窃听者（局域网/公网中间人）；T2 中继运营者或中继被入侵；T3 手机丢失/被盗者；T4 宿主上的恶意软件；T5 暴力破解者；T6 供应链投毒；T7 客户端 XSS/恶意网页。

## 对策（TM-001..013）

| ID | 对策 | 抗 | 验收方法/检查点 |
|---|---|---|---|
| TM-001 | 传输加密：中继走 rathole noise；直连提示局域网信任或 HTTPS | T1 | 中继抓包只见密文（对应 REQ-014） |
| TM-002 | 零知识中继：只转发密文，不落地存储会话内容 | T2 | 中继无内容存储代码路径；审计检查 |
| TM-003 | 凭据分层：密码仅用于绑定流程，日常用 device_token（宿主存摘要不存明文） | T1/T5 | 绑定后日志无密码传输 |
| TM-004 | 挑战-应答绑定：nonce 一次性，签名绑定公钥，防重放 | T1/T5 | 重放同 nonce 请求被拒（测试用例） |
| TM-005 | 设备吊销即时生效：注册表移除 → rathole 热重载断隧道 → 凭据心跳 401 | T3/T2 | 吊销后该设备凭据/grant 立即失效 |
| TM-006 | 手机侧私钥不可导出（WebCrypto extractable:false），重装即需重新配对 | T3 | 浏览器 CryptoKey 属性断言 |
| TM-007 | 第三方 key 只存宿主（dsh-credentials），手机/中继不接触 | T2/T4 | 客户端代码无 key 字段（REQ 见 ADR-013） |
| TM-008 | 权限闸门：DSH permission presets + 审批；目录浏览范围策略 + 全盘二次确认 | T4 | 越界请求 `scope-denied`（REQ-008/009） |
| TM-009 | 抗暴力破解：12 字符随机密码 + 绑定接口限速 + 连续失败锁定 | T5 | 限速测试；锁定策略单测 |
| TM-010 | 供应链：依赖锁定、最小依赖、零 AGPL 依赖（四步法）、定期审计 | T6 | CI 依赖检查；许可清单 |
| TM-011 | 本地审计日志：只记元数据（时间/设备/方法/结果） | T4（事后） | 日志 schema 无内容字段（REQ-016） |
| TM-012 | 知情同意：语音/视觉通道单独确认后才启用 | T2（合规） | UI 首启确认流程（REQ-020/022） |
| TM-013 | 客户端硬化：严格 CSP、无第三方脚本、主控端 = 官方前端移植构建产物（附 THIRD_PARTY_NOTICES） | T7 | CSP 头检查；构建产物审计 |

## 残余风险（声明不防）

- **宿主已沦陷**（T4 成功）：恶意软件在宿主上=与任何远程工具同级的全盘沦陷——这不是协议能解决的，靠宿主自身安全。
- **官方 SaaS 内部人员**：Phase B 建立独立控制体系（权限分离/审计），本期不涉及。
- **密码被键盘记录**：宿主沦陷场景的延伸，同上。
